# Project rename: tpm-passkey

The user requested the entire project be renamed after the optional-PCR change
(commit d65e93e, all local checks and both software-TPM VM checks passed).

Rename scope: Cargo package/binary/crate, Nix overlay and service option,
systemd unit and assets, polkit action/vendor/URL, UHID names and udev matching,
management socket and default state paths, logging filters, tests and documents.
No compatibility aliases remain. Git history and repository checkout metadata
are not rewritten, and existing state directories are not automatically moved.
Pre-rename development stores remain ignored to prevent accidental disclosure.

Existing TPM blobs and stored policyRefs are never rewritten. The v1 recovery
AAD domains are immutable cryptographic format constants, retained as byte
escapes to preserve record compatibility without old product-name identifiers.
A fixed configuration/auth ciphertext fixture, generated by the old binary,
tests that old encrypted recovery records can still be unlocked and decrypted.
New credentials use the new product namespace for newly generated policyRefs.
No migration changes are needed.

Passed: nix fmt, cargo check, cargo test (86), CLI help, and daemon dry run.
Full `nix flake check -L` passed (Pueue task 9), including the renamed polkit
and optional-PCR software-TPM VM checks on the host system. A tracked-source
scan finds no remaining old project-name spellings; immutable recovery format
bytes are covered by the compatibility fixture test.
